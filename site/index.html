Quick start

  1. Install VS Code 1.100 or newer with GitHub Copilot Chat.
  2. Run Pareto GHC: Open Model Comparison and set your Artificial Analysis Free API key.
  3. Pick a task, billing mode, and token workload, then select a chart point or table row to inspect the tradeoff.
